# Student Performance Analysis

## Overview
A Python data analysis project exploring the relationships between students' study hours, attendance, and academic performance in mathematics and English.

## Objectives
- Inspect and summarize student data using pandas.
- Identify and handle missing values.
- Explore correlations between study hours, attendance, and math scores.
- Visualize patterns using Matplotlib.
- Communicate findings and limitations clearly.

## Tools and Libraries
- Python
- pandas
- Matplotlib
- Jupyter Notebook

## Project Files
- `student_performance_analysis.ipynb` — Notebook containing the analysis, statistics, visualizations, and conclusions.
- `students.csv` — Practice dataset used in the notebook.

## Key Findings
- The dataset contains 10 student records and 5 columns.
- One math score is missing, leaving 9 records for analyses involving math scores.
- The average math score is 80.44.
- The average English score is 81.89.
- Average study time is 3.56 hours, and average attendance is 82.78%.
- Study hours and attendance show very strong positive correlations with math scores in this dataset.

## Limitations
- The dataset is small and intended for practice.
- Missing math scores were excluded from analyses involving math scores.
- Correlation does not establish causation.
- The findings should not be generalized to all students.

## How to Run
1. Download or clone this repository.
2. Keep `students.csv` and `student_performance_analysis.ipynb` in the same folder.
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the cells from top to bottom.

## Future Improvements
- Analyze a larger, real-world dataset.
- Explore additional relationships among academic variables.
- Improve visualizations and compare findings across different groups.
